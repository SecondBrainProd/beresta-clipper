# Beresta Clipper — Chrome и Safari

Кнопка на панели браузера отправляет открытую страницу в Beresta статьёй во
«Входящие» (🌰). Один набор файлов на оба браузера: Safari исполняет
`chrome.*` и MV3, браузер определяет себя в рантайме и честно называет себя
в поводе журнала (`import:web:chrome` / `import:web:safari`).

Приёмная сторона и настройка Beresta — те же, что у Firefox-версии:
`packages/firefox-clipper/README.md` (включить приёмник в Параметрах →
«Вырезки», скопировать токен).

## Chrome — установка распакованным

Магазина не требуется:

1. `chrome://extensions` → включить «Режим разработчика» (справа сверху).
2. «Загрузить распакованное» → выбрать папку
   `packages/chrome-clipper/extension`.
3. В настройках расширения (правый клик по кнопке → «Параметры») вставить
   токен из Beresta.

Исход каждого клика приходит уведомлением. MV2-вариант для Chrome не
делается: Chrome его демонтировал, копия Firefox-версии не завелась бы.

## Safari — расширение едет внутри Beresta.app

Отдельно ничего не ставится: таргет `BerestaSafariClipper` собирается вместе
с приложением и лежит в `Beresta.app/Contents/PlugIns/`.

1. Собрать и запустить Beresta (`make run` или Xcode).
2. Safari → Настройки → Расширения → включить «Beresta Clipper».
   Если расширения в списке нет: Safari → Настройки → Разработка →
   «Разрешить неподписанные расширения» (пункт есть при включённом меню
   «Разработка»; при сборке с личной подписью Xcode не требуется).
3. При первом клике Safari спросит разрешение на `127.0.0.1` — разрешить.

Исход в Safari показывается значком на кнопке (✓ / ✕) — уведомлений для
web-расширений у Safari нет; подробность — в подсказке кнопки.

## Очередь, когда Beresta закрыта (с 1.0.0)

Если приёмник не отвечает, страница не теряется: она ложится в очередь в
хранилище расширения (`outbox.js`, общий файл трёх браузеров), на кнопке
видно число ждущих, и очередь уходит сама — при следующем клике, при запуске
браузера, раз в минуту и сразу после правки токена. Предел — 20 страниц и
8 МБ; сверх него человеку сказано, что страница НЕ сохранена. Неверный токен и
отказ Beresta по существу — не очередь, а уведомление с причиной на языке
браузера (по постоянному коду приложения, а не по его русской строке).
Постановка — `docs/plans/20260930-клипперы-публикация-постановка.md`.

## Пакеты для магазинов

`bash scripts/клипперы-пакеты.sh` — проверки и два zip в `dist/клипперы/`.
Что вписывать в поля магазинов — `docs/витрина/расширения/листинг.md`.

## Проверка

```sh
node packages/chrome-clipper/check.mjs
node --test packages/chrome-clipper/outbox.test.mjs
```

Входят в `make test` (цель `test-clipper`): манифесты обоих расширений,
версии совпадают, иконки есть и нужного размера, копия очереди у Firefox
совпадает побайтно, каталоги строк сошлись; очередь — 13 проверок без
браузера.
