# Beresta Clipper — расширение Firefox

Кнопка на панели браузера отправляет открытую страницу в Beresta, и та
становится статьёй во «Входящих» (🌰). Страница уезжает целиком
(`outerHTML`); картинки расширение не собирает — их дотягивает из сети сама
Beresta, тем же конвейером, что у статей Zotero.

Приёмная сторона — `ClipperService` в приложении: локальный HTTP на
`127.0.0.1` (порт по умолчанию 21120), слышен только этой машине, каждый
запрос — с токеном. План: `docs/plans/20260829-расширение-браузера.md`.

## Настройка

1. В Beresta: **Параметры → «Вырезки»** → включить приёмник. Там же показаны
   порт и токен.
2. В настройках расширения (Firefox → Дополнения → Beresta Clipper →
   Настройки) вставить токен; порт — только если в Beresta он нестандартный.
3. Открыть страницу, нажать кнопку «В Beresta». Исход придёт уведомлением:
   «Готово», «Уже в библиотеке» или что включить, если приёмник выключен.
   Страница не теряется: тот же клик повторяет отправку.

Повторная вырезка той же страницы дубля не заводит — статья находится по
адресу страницы и пропускается.

## Установка

Два пути, оба живут с self-hosted расширением без магазина:

**Временная загрузка (для проверки).** `about:debugging` → «Этот Firefox» →
«Загрузить временное дополнение…» → выбрать `extension/manifest.json`.
Живёт до перезапуска браузера.

**Постоянная (unlisted-подпись на AMO).** Firefox требует подписи даже вне
магазина. Один раз: завести ключи API на
<https://addons.mozilla.org/developers/addon/api/key/>, затем:

```sh
cd packages/firefox-clipper
npm install
npx web-ext sign --channel=unlisted --source-dir extension \
  --api-key "$AMO_JWT_ISSUER" --api-secret "$AMO_JWT_SECRET"
```

Подписанный `.xpi` появится в `web-ext-artifacts/` — он ставится через
«Установить дополнение из файла…» и переживает перезапуски.

## Проверка

```sh
cd packages/firefox-clipper
npm install
npm run lint   # web-ext lint по папке extension/
```
